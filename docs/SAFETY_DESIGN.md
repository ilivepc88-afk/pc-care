# 安全设计

## 核心原则

PcCare 只提供只读体检、只读启动项展示、本地报告和当前用户视觉效果优化。程序不包含文件扫描或删除能力，不接受任意路径、命令或注册表参数。

## 权限边界

- 主界面默认以普通用户启动。
- 体检、报告和性能优化均不申请管理员权限。
- 不包含提权子进程或 UAC 清理入口。

## 固定禁止项

- 文件清理、任意路径扫描或删除。
- 用户桌面、文档、下载、收藏夹、浏览器数据、网盘目录访问。
- 注册表清理和所谓无效注册表项。
- Prefetch、事件日志、Windows 更新数据库。
- Windows 服务、驱动、计划任务修改。
- Windows Update、Defender、安全策略、遥测、搜索索引修改。
- 内存“释放”、TCP 参数、HPET、电源和游戏优化。
- 在线脚本、插件、规则更新、远程接口和遥测。

## 数据与隐私

- 不联网，不上传任何信息。
- HTML 报告没有 CDN、在线字体、脚本或远程图片。
- 报告默认写入程序旁的 `Reports` 目录；目录不可写时使用当前用户文档目录。

## 视觉效果优化边界

- 只修改当前用户（HKCU）的视觉效果，不申请管理员权限。
- 使用 Windows `SystemParametersInfo` 接口关闭动画、淡入淡出、阴影和平滑滚动，并显式保持字体平滑开启。
- 只写入固定的 Explorer/DWM 视觉效果值，不接受任意注册表路径或参数。
- 不创建、读取或删除视觉效果备份，不提供恢复功能。
- 不结束 Explorer 进程，不强制注销或重启电脑。

## 当前剩余风险

视觉效果性能模式会覆盖当前用户的相关设置，且程序不创建备份。部分效果需要重新登录后完全生效；应用前必须由用户确认。
