# 安全设计

## 核心原则

PcCare 提供离线检查、保守启动项优化、后台优化、当前用户视觉效果优化及硬件与电源建议。程序不包含文件扫描或删除能力，不接受任意路径、命令或注册表参数。

## 权限边界

- 主界面默认以普通用户启动。
- 检查和性能优化均不申请管理员权限。
- 仅在用户确认修改 HKLM、公共启动文件夹或第三方计划任务时，为单个固定启动项操作请求 UAC。
- 提权子进程只接受序列化的启动项操作，并再次验证来源必须是固定的 Run/Run32、StartupFolder 或非 `\Microsoft\Windows\` 的计划任务；不能执行任意命令或写入任意注册表路径。

## 固定禁止项

- 文件清理、任意路径扫描或删除。
- 用户桌面、文档、下载、收藏夹、浏览器数据、网盘目录访问。
- 注册表清理和所谓无效注册表项。
- Prefetch、事件日志、Windows 更新数据库。
- Windows 服务、驱动修改。
- 删除计划任务、启动项文件、注册表 Run 值或 UWP 项。
- Windows Update、Defender、安全策略、遥测、搜索索引修改。
- Windows 防火墙、UAC、SmartScreen、BITS、SysMain、WMI、通知、剪贴板、最近文件/Jump List、全局后台应用开关。
- 卸载或删除 AppX、Edge、WebView2、Windows 组件或浏览器配置文件。
- 内存“释放”、TCP 参数、HPET 和游戏优化。
- 在线脚本、插件、规则更新、远程接口和遥测。

## 数据与隐私

- 不联网，不上传任何信息，也不生成或保存检查报告。

## 视觉效果优化边界

- 只修改当前用户（HKCU）的视觉效果，不申请管理员权限。
- 使用 Windows `SystemParametersInfo` 接口关闭动画、淡入淡出、阴影和平滑滚动，并显式保持字体平滑开启。
- 只写入固定的 Explorer/DWM 视觉效果值，不接受任意注册表路径或参数。
- 不创建、读取或删除视觉效果备份，不提供恢复功能。
- 不结束 Explorer 进程，不强制注销或重启电脑。

## 当前剩余风险

视觉效果性能模式会覆盖当前用户的相关设置，且程序不创建备份。检查会先只读显示当前配置；应用前必须由用户确认。部分效果需要重新登录后完全生效。

## 启动项优化边界

- 扫描范围仅限 HKCU/HKLM Run、RunOnce、WOW6432Node Run/RunOnce、用户/公共启动目录、`StartupApproved` 状态和拥有登录/开机触发器的计划任务。
- 默认不显示 `\Microsoft\Windows\` 任务；即使用户选择显示，系统任务仍不可修改。
- Run/启动文件夹的禁用和启用只更新对应 `StartupApproved` 二进制状态的首字节，保留原始值的其它字节，不删除 Run 值或文件。RunOnce 因缺少可靠的通用禁用机制，只读展示。
- 计划任务只调用 Windows 计划任务的 `Enabled` 属性，不删除任务；UWP StartupTask 本期不扫描、不修改。
- 企业安全、EDR、终端管控、VPN、驱动、硬件控制和 Microsoft Windows 系统组件默认保护。未知项允许用户逐项确认，但绝不进入一键优化。
- 操作结果只在当前界面反馈，不保存完整命令行、凭据或历史报告。

## 后台优化边界

- 只处理 Windows 提示/推荐、Consumer Experience、已检测功能的 Widgets/News and interests/Copilot、浏览器后台模式、个性化体验、广告 ID 和 Spotlight。
- 所有可写项来自固定规则表。界面和 UAC 子进程仅传递规则 ID 与操作类型，不接收任意注册表路径、PowerShell 或命令。
- 同名 HKCU/HKLM 策略值已存在且不是 PcCare 创建时，显示为“组织策略”并拒绝覆盖；Edge 与 Chrome 同样遵守此规则。
- “恢复默认”仅删除 PcCare 创建且带本地所有权标记的值；不保留旧值、不创建备份、不创建还原点、不删除企业策略。
- 操作结果只在当前界面反馈；不生成历史报告或持久化操作日志。

## 硬件与电源边界

- 仅使用固定 Windows 电源计划 GUID 和固定子组/设置 GUID；不解析本地化计划名称，也不接受任意 `powercfg`、PowerShell 或命令行参数。
- 只允许在适用设备上切换既有的平衡/高性能内置计划、写入 AC CPU 最大状态、台式机 HDD 空闲时间，以及可选的 PCIe Link State 值；全部需要用户确认。
- 不修改 CPU 最小状态、电池 DC 策略、休眠、快速启动、虚拟内存、USB、服务、BIOS、固件、超频、电压、TDP、C-state 或定时器设置。
- 组织策略/MDM、OEM 电源管理组件和虚拟机会被保守处理；企业策略不覆盖，自定义/OEM 电源计划不删除、不重命名、不恢复默认。
- 电源执行记录只在当前会话显示，不写入磁盘或导出报告。
