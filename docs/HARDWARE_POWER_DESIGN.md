# 硬件与电源模块设计

## 目标与边界

模块只读取本机硬件、供电和 Windows 电源计划，并依据设备类型给出保守建议。它不联网、不安装服务、不使用 WMI 或大型第三方库，也不依赖电源计划的本地化名称。

## 检测方式

- CPU、内存、系统根目录和供电状态使用 Windows 原生 API 与只读注册表。
- 系统盘通过卷到物理磁盘映射、存储描述符和 Seek Penalty 查询识别 HDD/SSD/NVMe 与总线类型。
- 电源计划和 AC/DC 参数通过 `powrprof.dll` 的 GUID 接口读取/写入；内置计划以固定 GUID 判断。
- Windows 版本由注册表产品信息和 Build 号读取，避免仅依赖 `OSVersion` / `GetVersionEx`。

## 允许的写入

仅在用户确认、当前硬件适用且未受组织/OEM 管理时，可执行以下固定操作：切换到现有的平衡或高性能内置计划、将 AC CPU 最大状态设为 100%、将台式机 HDD 空闲时间设为 20 分钟，以及老旧台式机可选关闭 PCIe Link State 节能。恢复只针对当前 Windows 内置的平衡/高性能/节能计划默认值。

## 禁止的写入

不创建卓越性能计划；不超频，不写 BIOS、CPU/GPU 电压、TDP、C-state、虚拟内存、定时器、USB、服务、睡眠/休眠/快速启动设置；不删除或重命名自定义/OEM 电源计划；不创建备份、还原点或持久化操作日志。

## 企业和设备保护

检测到策略/MDM 电源节点时，所有电源写入均锁定。虚拟机不提供物理硬件升级建议，也不进入电源一键推荐。确认存在 Lenovo、Dell、HP 厂商管理组件时同样阻止自动写入，避免与 OEM 策略竞争。
