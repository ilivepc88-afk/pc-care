# 当前版本验收标准

## 构建

- [ ] Windows GitHub Actions 能够恢复、编译并通过全部测试。
- [ ] 发布 `win-x64` 自包含单文件离线版并生成 SHA256 文件。
- [ ] 发布 `win-x64` 框架依赖单文件轻量版并生成 SHA256 文件。
- [ ] Actions 摘要显示两个 EXE 的实际字节数。

## 检查

- [ ] 普通用户能够启动程序并完成只读检查。
- [ ] 显示 Windows、CPU、内存、系统盘、磁盘类型、运行时间、权限和待重启状态。
- [ ] Windows 11 企业版 LTSC 不识别为 Windows 10。
- [ ] 单项读取失败时显示无法读取，程序不崩溃。
- [ ] 界面和代码中均无文件清理功能。

## 启动项

- [ ] 显示 HKCU/HKLM Run、RunOnce 与 HKLM WOW6432Node Run/RunOnce 项。
- [ ] 显示用户和公共启动目录，并识别常见 `StartupApproved` 启用状态。
- [ ] 显示有登录或开机触发器的计划任务，默认隐藏 `\Microsoft\Windows\`；勾选显示后仍不可修改系统任务。
- [ ] 文件元数据或签名读取失败不阻塞全量扫描。
- [ ] Run、启动文件夹只通过固定的 `StartupApproved` 状态层启停，不删除原始值或文件；RunOnce 只读。
- [ ] 第三方登录/开机计划任务只切换 Enabled，不删除任务。
- [ ] 未知、系统、安全、企业管理、驱动和硬件控制项不能进入一键优化。
- [ ] 一键优化只处理“已启用 + 建议优化 + 低风险 + 可操作”的项目，并要求确认。
- [ ] 修改 HKLM、公共启动目录或第三方计划任务仅按单项按需请求 UAC。

## 性能优化

- [ ] 二次确认后，仅保留字体平滑并关闭其他视觉效果。
- [ ] 只修改当前用户设置，不申请管理员权限。
- [ ] 不创建或读取备份，不显示恢复按钮。
- [ ] 性能页不显示“将关闭的项目”提示块及其项目文字。

## 后台优化

- [ ] 只显示受支持或可安全判定的推荐/浏览器后台项；不提供全局后台应用、通知、剪贴板或最近文件优化。
- [ ] 一键优化仅处理“低风险 + 推荐 + 支持 + 可优化”项目，且要求确认。
- [ ] Widgets、News and interests、Copilot 和浏览器均按实际功能/安装状态检测；未检测到则显示系统不支持。
- [ ] HKCU/HKLM 同名策略值存在且非 PcCare 所有权时显示组织策略，不能覆盖或删除。
- [ ] HKLM 项目沿用单次固定 UAC 操作；HKCU 项目不提升权限。
- [ ] 恢复默认只删除 PcCare 创建的值和所有权标记，不创建注册表备份、JSON 备份或还原点。
- [ ] 不生成或导出 HTML、JSON 报告。

## 性能配置读取

- [ ] 执行“开始检查”后，性能页显示当前用户的视觉效果预设、字体平滑、窗口动画、拖动内容、界面效果和各动画开关。
- [ ] 性能模式操作完成后自动重新读取并刷新当前配置。

## 硬件与电源

- [ ] 读取 CPU、内存、系统盘型号/介质/总线、设备类型、供电状态和当前电源计划；单项失败不使检查崩溃。
- [ ] Windows 10/11/LTSC 使用产品信息与 Build 号识别，不只依赖 `OSVersion` / `GetVersionEx`。
- [ ] 台式机、笔记本、虚拟机、HDD/SSD/NVMe、4/8/16 GB 内存得到不同且可解释的建议。
- [ ] 一键仅处理低风险、推荐、适用且可写的项目；PCIe 和恢复内置计划默认值不能进入一键。
- [ ] 不提供 CPU/GPU 超频、BIOS/电压/TDP、休眠、快速启动、虚拟内存、USB、服务或卓越性能计划创建。
- [ ] 检测到组织策略/MDM 或 OEM 电源管理组件时不覆盖；虚拟机不提供物理硬件升级建议。

## 实机试点

- [ ] Windows 10 普通用户测试。
- [ ] Windows 11 企业版 LTSC 普通用户测试。
- [ ] 125% 和 150% 缩放测试。
- [ ] 至少 5 台非关键办公电脑试点，确认业务软件和用户文件不受影响。
