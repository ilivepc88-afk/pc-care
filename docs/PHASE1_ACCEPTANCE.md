# 第一阶段验收标准

## 构建

- [ ] Windows GitHub Actions能够恢复、编译并通过全部测试。
- [ ] 能发布`win-x64`自包含单文件`PcCare.exe`。
- [ ] 同时生成SHA256文件。

## 体检

- [ ] 普通用户能够启动程序并完成只读体检。
- [ ] 显示Windows、CPU、内存、系统盘、磁盘类型、运行时间、权限和待重启状态。
- [ ] 单项读取失败时显示无法读取，程序不崩溃。

## 清理

- [ ] 默认只列出超过7天且未占用的文件。
- [ ] 删除前显示文件数、预计容量和风险说明。
- [ ] 缩略图缓存默认不勾选。
- [ ] 清理前再次确认并按需触发UAC。
- [ ] 提权进程只接受固定分类ID并重新扫描。
- [ ] 文件删除失败时继续处理其他文件。
- [ ] 不跟随符号链接、目录联接点或其他重解析点。
- [ ] 不扫描或删除白名单目录之外的文件。

## 启动项

- [ ] 显示HKCU/HKLM的32位和64位Run项。
- [ ] 显示用户和公共启动目录。
- [ ] 第一阶段不允许修改启动项。

## 报告

- [ ] 导出HTML和JSON。
- [ ] HTML完全离线打开，不包含远程资源。
- [ ] HTML对计算机名、命令和其他动态文本做编码。

## 实机试点

- [ ] Windows 10普通用户测试。
- [ ] Windows 11普通用户测试。
- [ ] UAC取消测试。
- [ ] 管理员清理测试。
- [ ] 125%和150%缩放测试。
- [ ] 至少5台非关键办公电脑试点，确认业务软件和用户文件不受影响。
